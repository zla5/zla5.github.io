手机端使用（推荐）

通话翻译已集成到 WATransChat，开通会员后直接在手机上与客户语音/视频通话翻译，无需安装额外软件。

使用步骤

  1. 在手机上安装 WATransChat（安卓 / iOS），使用您的账号登录。 下载方式见 WATransChat 多平台下载。
  2. 联系客服开通通话翻译会员（与 WATransChat 共用账号，语音翻译为独立订阅）。
  3. 在 WATransChat 中进入 WhatsApp，选择客户发起语音或视频通话。
  4. 开启通话翻译功能，即可在通话过程中实时双向翻译，原文与译文同步显示在界面上。

手机端适合在 WhatsApp 上直接与客户沟通的场景。如需在 Zoom、Teams、微信等其它软件中通话翻译，请使用下方 电脑端独立软件。

电脑端安装与配置

除 WhatsApp 手机通话外，Zoom、Teams、微信、QQ 等软件仍需使用 Windows 独立版。按顺序完成驱动安装、软件登录与接口配置即可。

安装步骤

  1. 分别下载 软件安装包 与 虚拟音频驱动。
  2. 解压 VBCABLE_A_B_Driver_Pack43.zip，得到 VBCABLE_A_Driver_Pack43 与 VBCABLE_B_Driver_Pack43 文件夹（若仍为 zip，请再分别解压）。
  3. 进入 VBCABLE_A_Driver_Pack43 文件夹，右键 VBCABLE_Setup_x64.exe，选择以管理员身份运行完成安装。
  4. 进入 VBCABLE_B_Driver_Pack43 文件夹，同样右键 VBCABLE_Setup_x64.exe，选择以管理员身份运行完成安装。
  5. 双击运行 CallTranslator-0.1.2.exe，按向导安装软件。如弹出安全提示窗口，点击更多信息，选择仍要运行。
  6. 启动外贸通话翻译官，使用你的 WATransChat 账号与密码登录。
  7. 获取接口 Key：打开 火山引擎豆包同声传译控制台，使用手机号登录；如需实名验证，请先完成实名。页面会显示豆包同声传译大模型，点击试用，复制下方的 APP ID 与 Access Token，填入软件内的接口设置。
  8. 在软件中进入音频设备设置，按界面文字提示选择正确的输入、输出设备。
  9. 在微软商店搜索并安装 WhatsApp 电脑版，扫码关联手机 WhatsApp 完成登录。找一位联系人发起语音通话，在通话界面点击麦克风，再按外贸通话翻译官内的提示完成麦克风与路由配置。
  10. 全部设置完成后，在软件中点击开始翻译通话，即可开始使用双向实时翻译。

驱动安装后建议重启电脑。电脑端适用于 Zoom、Teams、微信、QQ 等更多通话软件；若仅需在手机上与客户 WhatsApp 通话翻译，推荐使用上方 WATransChat 手机端。安装或接口填写遇到问题，可 联系微信客服获取协助。

常见问题

手机端怎么用？需要单独装软件吗？

不需要。通话翻译已集成到 WATransChat 手机 App 中，开通通话翻译会员后，在手机上即可与客户进行 WhatsApp 语音/视频通话实时翻译。 详见手机端使用说明。

电脑端一定要装驱动吗？

使用 Windows 独立版在 Zoom、Microsoft Teams、Google Meet、Discord、Telegram、微信、QQ 等电脑语音通话场景下，需要先安装页面提供的音频驱动并重启电脑。 详细步骤见电脑端安装与配置，也可咨询客服。

下载不了安装包怎么办？

请联系微信客服获取最新安装包与驱动下载链接。

第一次使用不会配置？

软件内有操作引导；也可添加客服微信，获取图文教程或预约协助配置。

提示账号已在其他电脑登录？

请在已登录的电脑上先退出账号，或联系客服处理后再登录。

安装后没有声音或无法翻译？

请确认已重启电脑、会员在有效期内，并检查软件内音频设备是否选择正确。仍无法解决请联系客服。
