语音通话显示「连接中」

通常是您的国际互联网不支持 UDP 协议，导致语音通话一直停在「连接中」。 请在国际互联网软件中添加一条绕过路由。

NekoBox 安卓国际网络软件下载（GitHub Releases） → Hiddify 苹果手机国际网络软件下载（App Store） →

如果你的节点无法导入到 NekoBox 或 Hiddify，请联系你的网络供应商，就说：我要在 NekoBox 或 Hiddify 中使用这个节点，要怎么做。

教学视频

添加路由设置

  1. 打开你的国际互联网软件，新增一条路由。
  2. 路由名称填写：语音通话（可自定义）。
  3. dst port 填写：3478。
  4. network 选择：TCP and UDP。
  5. Outbound 选择：绕过。
  6. 保存并启用这条路由后，再重新发起语音通话。
字段 填写内容
路由名称 语音通话
dst port 3478
network TCP and UDP
Outbound 绕过

保存并启用该路由后，再试语音通话。若仍显示「连接中」，请确认规则已生效。
